# Jogo da Forca em Java 🎮

Projeto prático desenvolvido no 2º período. Trata-se do clássico jogo da forca, executado diretamente no terminal.

## O que o código faz:
- Permite adivinhar a palavra letra a letra ou escrever "PALPITE" para tentar acertar a palavra inteira de uma só vez.
- Mantém um sistema de pontuação dinâmico (começa com 1000 pontos e deduz 150 pontos por cada letra errada).
- Controla o limite máximo de 6 erros e exibe as letras que já foram tentadas pelo jogador.
- Oferece a opção de jogar novamente no fim da partida.
